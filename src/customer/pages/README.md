# Customer Pages

Customer storefront and studio pages are routed via TanStack Start:
- `src/routes/index.tsx` -> Home Page / Store Showcase
- `src/routes/studio.tsx` -> Interactive 3D/2D Custom Apparel Builder
- `src/routes/products.tsx` -> Apparel Catalog
- `src/routes/cart.tsx` -> Shopping Cart
- `src/routes/order-review.tsx` -> Checkout Review & Payment
- `src/routes/orders.tsx` -> Customer Orders History
- `src/routes/profile.tsx` -> Account Profile
- `src/routes/pricing.tsx` -> Bulk Pricing Calculator
- `src/routes/about.tsx` -> About Custom On
- `src/routes/contact.tsx` -> Contact & Inquiries
